# CLICKPOCALYPSE Six-Hour Sprint Plan

The complete solo journey is the only release gate. Multiplayer/audience voting is forbidden until the MVP journey is deployed and rehearsed.

## 00:00–00:20 — Step 0: PRD, architecture, and bootstrap

- Lock thresholds, shared contracts, store semantics, ownership, and acceptance criteria.
- Bootstrap strict React/Vite/Tailwind, tests, lint, build, and placeholder.
- Dispatch the three ready-to-paste prompts.

**Checkpoint:** clean install and all local checks pass; all agents acknowledge file ownership.  
**Fallback:** omit optional libraries/assets and begin against placeholder contracts; never relax the contract.

## 00:20–02:00 — Parallel implementation

- Agent 1 builds premium landing, responsive identity, CTA, and sanity meter.
- Agent 2 builds semantic interaction routing, 13 authored beats, and cleanup-safe effects.
- Agent 3 builds court state, evidence exhibits, defenses, verdict, certificate, mute/audio fallback.
- Integration lead reviews exports and prepares `App.tsx` wiring without editing agent-owned files.

**Checkpoints:**

- 00:50: each feature renders independently with typed public exports.
- 01:20: agents demonstrate their critical path and reduced-motion fallback.
- 01:45: feature work freezes for local verification and handoff notes.
- 02:00: all three pass typecheck/build in the shared tree or report exact owned failures.

**Fallback:** at first missed checkpoint, cut decorative variants, extra sections, physics, and nonessential audio. Preserve one polished landing view, one response per count, and complete court/certificate flow.

## 02:00–02:50 — Integration and end-to-end completion

- Integration lead wires landing, effects, court, persistent controls, and reset.
- Verify each count boundary, final evidence record, courtroom mount, verdict, certificate fallback, and replay.
- Resolve imports and ownership requests centrally.

**Checkpoint:** one uninterrupted desktop journey completes in under two minutes by 02:35; mobile and reduced-motion complete by 02:50.  
**Fallback:** replace fragile transitions with immediate scene swaps; replace PNG export with a print-friendly certificate; use CSS-authored meltdown instead of physics.

## 02:50–03:50 — Animation and comedy polish

- Tighten beat timing, copy callbacks, visual rhythm, sound levels, and premium-to-chaos contrast.
- Add only improvements that preserve deterministic completion and cleanup.
- Rehearse with someone who has not seen the experience.

**Checkpoint:** every interaction has a distinct readable payoff; three consecutive replays show no leaked effects.  
**Fallback:** cut slow setup text, overlapping gags, heavy particles, and any joke requiring explanation.

## 03:50–05:00 — Bug fixes and selective enhancements

- Prioritize blockers, evidence accuracy, unreachable controls, mobile overflow, performance, then visual defects.
- Run keyboard, mute, missing-audio, reduced-motion, and narrow-screen journeys.
- Add stretch polish only after two clean end-to-end runs.

**Checkpoint:** checks pass, console is clean, and severity-1/2 defects are zero by 04:40.  
**Fallback:** disable failing optional effects behind capability checks; keep stable text/CSS fallbacks. No multiplayer work if any core defect remains.

## 05:00–05:25 — Deployment and production verification

- Push the verified commit and configure Cloudflare Pages: `npm run build`, output `dist`.
- Test the production URL on desktop and one mobile device/network.
- Confirm fonts/assets/audio/certificate/replay and direct loading.

**Checkpoint:** production completes the two-minute path twice by 05:20.  
**Fallback:** serve the local production preview for judging, retain a zipped `dist`, and prepare the backup recording while deployment is retried.

## 05:25–06:00 — Feature freeze, rehearsal, and submission

- Freeze features. Only fix demo-blocking regressions with immediate retest.
- Rehearse a scripted two-minute route, one recovery route, and the 20-second pitch.
- Verify submission link, README/run commands, backup recording, local preview, charger/network, and presenter controls.

**Checkpoint:** final production and offline/local backup are ready by 05:45; remaining time is rehearsal only.  
**Fallback:** demo the known-stable route, skip optional effect branches, and use the recording if network or deployment fails.
